## If you want to try it (sizing)
Base the size on how much you can stand to lose, divided by twice the trader's historical max drawdown. For example, if you can stand to lose $500: CPHequities gets about **$750** ($500 ÷ 66%), and JeppeKirkBonde gets about **$960** ($500 ÷ 52%). eToro's minimum copy is $200. Set a copy stop-loss at that loss level, and don't add @thomaspj on top, because it would double up the chip bets.
